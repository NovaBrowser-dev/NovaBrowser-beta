# NovaBrowser

NovaBrowser is an open-source web browser currently in early development.

## Goal

The goal of NovaBrowser is to build an accessible, community-driven, and openly developed browser. The project will be developed transparently, with public documentation, issue tracking, and an open contribution process.

## Status

NovaBrowser is currently in pre-launch development. The first public release is under preparation.

## Contributing

Contributions, feedback, bug reports, and feature ideas will be welcome once the initial project structure is ready.
